## How to Capture Screenshots

### Using Browser DevTools:
1. Open http://localhost:5174/ in Chrome/Edge
2. Press F12 to open DevTools
3. Click device toolbar icon (or Ctrl+Shift+M)
4. Set dimensions (1920x1080 for desktop, 375x667 for mobile)
5. Press Ctrl+Shift+P, type "screenshot", select "Capture full size screenshot"

### Using Windows Snipping Tool:
1. Open each page at http://localhost:5174/
2. Press Win+Shift+S to open Snipping Tool
3. Capture each page and save with appropriate filename
