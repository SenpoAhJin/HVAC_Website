## 📋 Your Next Steps (In Order)

### Step 1: View the Site (5 minutes)

Open a terminal in this folder and run:
```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser to see your site.

**Look through all pages:**
- Home
- Services  
- About
- Contact

Notice the placeholders (phone numbers, text, etc.) - you'll replace these next.

### Step 5: Add Your Photos (1 hour)

2. Compress them using https://tinypng.com

4. Organize in subfolders by category

**Categories to include:**
- Installation work
- Repair work
- Team at work
- Service vehicles
- Before/after shots

---

### Step 6: Get API Keys (30 minutes)

You need two API keys for the site to work:

**A. OpenAI (for chatbot):**
1. Go to https://platform.openai.com
2. Sign up and get an API key
3. Cost: ~$0.002 per conversation (~$5-20/month)

**B. Email Service (for contact form):**
1. Recommended: Go to https://resend.com
2. Sign up for free account
3. Get API key
4. Free tier: 100 emails/day

📄 **Detailed instructions:** See `DEPLOYMENT.md` Step 2

---

Before deploying, test:
- [ ] All phone numbers work

- [ ] Contact form submits
- [ ] Chatbot responds appropriately
- [ ] Site looks good on mobile
- [ ] All pages load correctly

### Step 8: Deploy to Vercel (30 minutes)

📄 **Full guide:** `DEPLOYMENT.md`

**Quick version:**
1. Push code to GitHub
2. Connect Vercel to your GitHub repo
3. Add your API keys as environment variables
4. Click deploy
5. Your site is live!

**Cost:** Free for hosting (you only pay for API usage)
